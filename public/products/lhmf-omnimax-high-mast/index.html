Highlights & Features

OmniMax: one pole, four fixtures, 360° of coverage.

Five reasons OmniMax wins the spec sheet — unique 165° optical-assembly rotation, 8-step WATTSELECT, 107,250 lm @ 143 lm/W (class-best), 10-year warranty, and IP65 die-cast for ports and highways.

— Hero Highlight

165° Optical Rotation.

The optical assembly rotates 165° left-to-right at the housing pivot. One pole can crown four OmniMax fixtures aimed at four different sectors — port quay + container yard + access road + perimeter — from a single mast. No other LED high-mast in the spec category offers this. Holophane HMAO LED IV: fixed. Cooper Galleon GLEON: fixed. Generic 750W high-mast: fixed.

Field-Adjustable

8-Step WATTSELECT.

Behind the access door, a 1-8 dial fields output at 25/40/50/60/70/80/90/100% of class max. The 750W class covers 200-750W in 8 SKU-free steps. Peers offer 0-3 steps. Stock one SKU; commission to any wattage point at install.

Output

107,250 lm @ 143 lm/W.

The 750W cell delivers what 1000W HID used to. Constant 143 lm/W across the entire 8-step range — efficacy doesn't drop as you dial down.

Adaptive Controls

8-step dial. Photocell-ready. 0-10V dimmable.

Behind the access door, an 8-position dial fields output from 25% to 100% of class max — one SKU, eight commissioning points. Every OmniMax housing ships with a 3-pin (ANSI C136.10) twist-lock photocell receptacle on top. Layer in 0-10V class-2 dimming and an optional PIR motion sensor for full dusk-to-dawn schedule + occupancy reduction. No gateway, no mesh, no commissioning app.

01

8-Step WATTSELECT Dial.

Behind the door, a 1-8 dial commissions the wattage to the IES target — 25/40/50/60/70/80/90/100% of class max. The 750W class covers 200/300/375/450/525/600/675/750W in 8 SKU-free steps. Ship one SKU; commission to any wattage point on the pole. Constant 143 lm/W across all 8 steps.

  • Factory default = position 8 (full output)
  • Field-commissionable · M6 hex wrench access
  • 16 wattage points across both housings (500W + 750W)
02

Photocell-Ready.

3-pin (ANSI C136.10) twist-lock receptacle on every housing — ships with a shorting cap when no photocell ordered. Add the optional ALG photocontrol (LSBX-L1/PCS/UM3 for 120-277V or LSBX-L1/PCS/HM3 for 277-480V) or any compliant photocell — vendor-neutral by design.

  • RB3 · 3-pin twist-lock standard on every SKU
  • Optional UM3 (120-277V) or HM3 (277-480V) photocell
  • Shorting cap shipped when no photocell ordered
03

0-10V Dimming + PIR.

Driver supports 0-10V class-2 dimming standard (also accepts 1-10VDC, PWM, or resistance-based). Add the optional integrated PIR motion sensor for dusk-to-dawn occupancy reduction at port terminals, truck stops, and large-area parking. Flicker < 5%, PF ≥ 0.9, THD ≤ 20%.

  • 0-10V class-2 std · 1-10VDC / PWM / R-dim accepted
  • Optional PIR — bi-level dim on vacancy
  • Flicker < 5% · PF ≥ 0.9 · THD ≤ 20%

No mesh, no gateway, no commissioning app. The 8-step dial behind the access door, the photocell on top, and the 0-10V dim pair on the driver — three controls inputs that work with the tools your installer already carries on the truck.
