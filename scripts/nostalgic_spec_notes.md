# Nostalgic A19 Full Specification Layout Reference

## Structure
- Section header: "FULL SPECIFICATIONS" (eyebrow with rule)
- Headline: "Spec sheet for the lamp · designer-grade detail."
- Left sidebar: numbered section list (01 Color & Filament, 02 Electrical, 03 Dimming & Controls, 04 Materials & Finish, 05 Compliance & Warranty)
- Right content: each section has a number (01, 02...), section title as h3, then rows of label + value pairs

## Each spec row
- Label (left, monospace, small, uppercase, muted)
- Value (right, normal weight)
- Divider line between rows

## Sections
01 Color & Optical: CCT options, CRI, MacAdam binning, Glass options, Beam distribution
02 Electrical: Input voltage, Wattage range, Lumen output, Efficacy, L70 life
03 Dimming & Controls: Dimming types, Dim-to, Compatible systems, Dim-to-warm
04 Materials & Finish: Base, Envelope, Glass, Filament style, MOL
05 Compliance & Warranty: Safety, Energy code, Warranty, RoHS

## Visual style
- Light beige/cream background (#f5f0e8 or similar)
- Left sidebar has dashed border boxes around each item
- Section numbers in accent color (amber/gold)
- Clean table-like rows with horizontal rules
